# Размещение базовых станций с учётом сетей конкурентов

Код, результаты и интерактивная карта к работе «Размещение базовых станций сотовой связи с учётом сетей конкурентов по открытым данным: субмодулярная оптимизация охвата населения Санкт-Петербурга и Ленинградской области».

Интерактивная карта рекомендованных мест для каждого оператора: файл `index.html` (открывается в браузере без сервера; при включённых GitHub Pages доступна по адресу репозитория).

## Структура

- `src/` — конвейер расчёта (запуск из корня, `PYTHONPATH=src`):
  1. `00_population.py` — разбор таблиц численности Петростата и сопоставление с границами OSM;
  2. `01_demand.py [k_house]` — оценка числа жителей по зданиям, проверка на районах и МО;
  3. `02_sites.py` — площадки операторов по реестру базовых станций;
  4. `03_coverage.py [МГц]` — матрица потерь «кандидат — ячейка» (COST-231 Hata, покров, дифракция на рельефе);
  5. `04_extend.py` … `15_ookla.py` — эксперименты (достройка, ILP, «с нуля», скрытая часть сети, чувствительность, бюджет, вероятностная постановка, отжиг, малые посёлки, проверка по Ookla);
  6. `09_figures.py`, `17_figures2.py` — рисунки; `16_mapdata.py`, `16b_water.py` — данные для карты.
  `opt.py` — ленивый жадный алгоритм, CELF, локальный поиск, точная модель (HiGHS); `common.py` — целевые функции.
- `data_prep/` — загрузка рельефа и покрова (`download_pilot_data.py`) и выгрузка слоёв из OSM (`extract_v2.py`).
- `results/` — таблицы с результатами экспериментов; `recommended_sites.csv` — ранжированные списки мест (первые 100) для каждого оператора в вариантах A (прирост охвата) и B (выигранный у конкурентов охват).
- `figures/` — рисунки статьи.

## Данные

Исходные данные в репозиторий не включены из-за объёма; все они открытые:

- OpenStreetMap, выгрузка Geofabrik по СЗФО → `data_prep/extract_v2.py` → `data/osm.gpkg`;
- реестр базовых станций с карты infocelltowers.ru → `data/towers.csv`;
- Copernicus DEM GLO-30 и ESA WorldCover 2021 v200 → `data_prep/download_pilot_data.py` → `data/dem/`, `data/wc/`;
- численность населения по муниципальным образованиям на 01.01.2025 (Петростат, PDF) → `data/population/`;
- Speedtest by Ookla, мобильные тайлы, 4 кв. 2024 → `data/ookla/`.

## Зависимости

См. `requirements.txt`. Python 3.10+; для разбора PDF Петростата нужна утилита `pdftotext` (poppler).
